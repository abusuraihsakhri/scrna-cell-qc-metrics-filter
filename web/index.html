Single-cell RNA sequencing · Quality control

Cell QC metrics & filter

Compute per-cell library size, detected features, mitochondrial and ribosomal proportions from a dense gene-by-cell count matrix. Flag and export cells against adjustable thresholds.

Local-only processing. Files remain in your browser; there are no uploads or external services.

1. Input & thresholds

CSV layout: first column contains gene names; every other column contains one cell's nonnegative integer counts. First row contains cell IDs.

Thresholds are inclusive. A zero-count cell always fails. Default gene-name matching: mitochondrial MT- (case-insensitive), ribosomal RPL/RPS.
